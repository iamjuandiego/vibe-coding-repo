# iamjuandiego Portfolio

Personal portfolio of a Senior Backend Engineer focused on banking systems, event-driven architecture, reliability and observability.

Built with:

- React + Vite + TypeScript
- TailwindCSS
- React Router
- Framer Motion

Aesthetic inspired by *For All Mankind* (deep space + mission amber accents).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Project names and internal codenames have been anonymized for public display.
- `node_modules` and `dist` should not be committed (see `.gitignore`). If they are still present in the history, remove them with:

```bash
git rm -r --cached node_modules dist
git commit -m "chore: stop tracking node_modules and dist"
```
